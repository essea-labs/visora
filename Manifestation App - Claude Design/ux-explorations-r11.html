Feel: Each chip = one specific vision. Chip shows vision NAME (italic) + small CATEGORY badge to the right. Horizontally scrollable. User can have two Career visions and attribute the win to the right one.

Trade-off: each chip is longer, fewer fit on screen. Win data model gains visionId?: string field; winsForVision(id) selector replaces winsForCategory(kind) for Detail.
