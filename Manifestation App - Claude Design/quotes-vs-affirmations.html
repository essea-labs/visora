Quotes + affirmations — three integration options

Both serve "inspiration" but they differ: quotes = wisdom (third person, attributed), affirmations = identity (first person, anonymous). All three options below show the same Home tab — only the inspiration section differs.

Option A · Recommended

Drop quotes — only affirmations

Feel: Cleanest, most on-brand. The whole app is about "Who you're becoming" — first-person identity statements align perfectly. Quotes feel more general-wellness; affirmations feel like THIS app.

Trade-off: lose the variety of attributed wisdom. Affirmations alone can feel monotonous if not carefully tone-varied (gentle / bold / playful mix).

Feel: One "Inspiration" section. Both card types in the same strip. Affirmation cards are italic + no author; Quote cards are roman + "— Author". Tiny badge top-left tags the type. Algorithm mixes ~75% affirmations, ~25% quotes for variety.

Trade-off: subtle mixed metaphor — users might wonder why some say "I am" and others say "Be the". The two card styles can read as one feature though, if treated as variations of the same thing.

Feel: Affirmations strip stays as the main feature; quote becomes a small standalone "thought for the day" card below it. Different visual treatment so they don't compete. Quote has a quote-mark glyph, no photo, more like a postcard.

Trade-off: home tab gets crowded — ritual + affirmation strip + quote card = three sections. Cognitive load. Quote feels demoted (which it sort of is — it's now a supporting actor).

My recommendation: Option A. The app's whole identity is first-person becoming. Drop quotes from the home tab; if you ever want attributed wisdom, surface it elsewhere (a "Read" section in the affirmation library, attached to specific visions, etc).
