Scan to open in Expo Go

exp://192.168.0.93:8081
  1. Install Expo Go from the App Store on your phone.
  2. Make sure your phone is on the same WiFi as this Mac.
  3. Open the Camera app and point at the QR code (iOS), or use Expo Go's built-in scanner.
  4. The first launch will download + compile the bundle (~30s).
Heads up: Innerproof uses native modules (Skia, expo-audio, expo-haptics, apple-authentication) that may not run in Expo Go. If you see a red error screen, we'll need to build a dev client instead.
