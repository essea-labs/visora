## Architecture quick facts (verified 2026-06)
- All user data persists on-device via AsyncStorage + Zustand persist. Zero Supabase calls today.
- Ritual audio is **bundled** (`mobile/assets/audio/ritual/ritual.m4a`, `require()`'d into the JS bundle). Core experience is **fully offline**. Internet only needed for App Store subscription (once RevenueCat is wired).
- Audio session uses `playsInSilentModeIOS: true` but `staysActiveInBackground: false`. Plays in silent mode, does NOT keep playing when phone is locked or backgrounded.
